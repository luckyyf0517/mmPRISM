# CSL Recording Runbook

Status: draft
Owner: Semantic sign-language collection lane
Authority scope: Minimal operator procedure for video-guided CSL radar/reference recording.
Last reviewed: 2026-08-12

## Before A Session

1. Use the frozen CSL core/stress video list.
2. Allocate opaque participant/session IDs and record `professional_or_proficient_signer` or
   `video_guided_volunteer`.
3. Confirm consent for radar and reference-video recording.
4. Start the fixed radar/reference setup, verify storage and run one synchronization trial.

## Record Each Clip

1. Show the selected CSL reference video and Chinese meaning.
2. Let the participant replay and rehearse until ready.
3. Allocate a new `take_id` and start synchronized radar/reference capture.
4. Record one complete reproduction without trimming raw files.
5. Check that both files open, synchronization is usable and the visible motion is complete.
6. Accept the take or record a short failure reason. A repeat always gets a new `take_id`.

For the stress subset, record the fixed frontal, `30 degree`, `60 degree`, partial-hand-occlusion and
object-occlusion conditions. Do not repeat the full corpus or improvise extra conditions.

## End A Session

1. Check planned versus usable core/stress takes.
2. Back up raw files and produce checksums.
3. Save the compact session manifest with participant type and condition labels.
4. Keep identifiable contact/consent material outside the research package.

Pause only for practical failures: participant withdrawal, wrong reference item/ID, radar/reference failure,
unusable synchronization, storage pressure or unreadable files. Preserve failed attempts; do not overwrite them.
