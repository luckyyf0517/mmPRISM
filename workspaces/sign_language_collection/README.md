# Semantic Sign-Language Collection Workspace

Owns the new approximately 30-participant Chinese Sign Language (CSL) collection: fixed reference videos,
lightweight participant coordination, synchronized radar/reference acquisition, basic QC, and frozen handoff.
The intended mix is 3--4 professional/proficient CSL contributors if available plus video-guided volunteers.
Legacy self-collected non-semantic gestures remain outside this dataset.
