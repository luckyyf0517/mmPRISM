# Semantic Sign-Language Collection Workspace

Owns the new approximately 30-participant Chinese Sign Language (CSL) semantic corpus: protocol, recruitment,
synchronized radar/reference acquisition, semantic review, session QC, and frozen handoff manifest. Legacy
self-collected non-semantic gestures are outside the new cohort and cannot support translation claims.
