# Literature Reading Notes

This area tracks bibliographic references, paper-reading notes, and project-specific interpretation. Original
PDFs, arXiv source packages, and other local source copies belong under `sources/`, which is excluded from Git.
Only the index, citation metadata, and notes are versioned.

Reading notes are research context, not project Authority. A conclusion becomes a project rule only after an
explicit decision or promotion into [project Authority](../authority/00_INDEX.md).
